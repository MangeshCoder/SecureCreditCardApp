# Secure Credit EMI – Angular client

```bash
npm install
npm start        # ng serve on http://localhost:4200, calls the API at http://localhost:5080
npm run build    # production build in dist/
```

The API URL is configured in `src/environments/environment.development.ts` (dev) and
`src/environments/environment.ts` (production). See `../docs` for the step-by-step guide.
